how a minute earns its weight

steer (prompt or edit) → check (run it, failing counts) → follow through (edit again or commit). close the loop and the minute counts fully. leave an agent running on its own and it counts at 0.2×. go silent to debug and it fades out over 5 to 12 minutes instead of vanishing.

settings

your account and connections. this page talks only to your server.

account

not signed in.
an account is just a handle. pick one, it is yours. no password, no email.

github

connect github with oauth. you will go to github, approve, and come back here linked. we keep only your github username, never the oauth token.
repo webhook → POST /v1/integrations/github/webhook
signed with GITHUB_WEBHOOK_SECRET on the server.

slack

connect slack with oauth for /struggletime stats and submission + review notifications. you will go to slack, approve, and come back here linked. we keep only your slack user id.
slash command → POST /v1/integrations/slack/command
signed with SLACK_SIGNING_SECRET; notifications need SLACK_WEBHOOK_URL. both live in the server environment or secret store, never in this page.

your daemon

run the helper on your machine. it only ever sends metadata buckets.

struggletime-helper start --repo ~/my-project --user you

inspect before you trust: make inspect REPO=~/my-project
full setup: docs/setup.md in the repo.

privacy

profile public by default, logged hours private, submitted hours auditable. prompts, code, commands and screenshots are rejected by the server schema even if something tried to send them.
