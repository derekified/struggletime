install the daemon

The dashboard only shows hours the desktop tracker sends. Install once per machine, paste your API key, then leave it running.

  1. Get the code 
    git clone https://origin.cursor.com/derekified/struggletime.git
cd struggletime
  2. Install (Linux / macOS) 
    sh daemon/install.sh

    Windows PowerShell: powershell -ExecutionPolicy Bypass -File daemon\install.ps1

  3. Link your API key

    Generate a key under Profile, then:

    struggletime-helper apikey <paste-key-here>

    Or open the tray → set API key…

  4. Start tracking a project 
    struggletime-helper start --repo ~/my-project

    Check: struggletime-helper status · optional shell hook for tests/builds:

    # bash/zsh
source /path/to/struggletime/daemon/hooks.sh

# PowerShell ($PROFILE)
. C:\path\to\struggletime\daemon\hooks.ps1

Privacy: only metadata leaves your machine (no code, prompts, or screenshots). Inspect anytime with python3 daemon/tracker_inspect.py ~/my-project.
