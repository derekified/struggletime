install the daemon

The dashboard only shows hours the desktop tracker sends. Install once per machine, paste your API key, then leave it running.

  1. Get the code 
    git clone https://github.com/derekified/struggletime.git
cd struggletime
  2. Install (Linux / macOS) 
    make rust && make install-binaries

    Or download the Windows/macOS/Linux zip from Releases.

  3. Link your API key

    Generate a key under Profile, then:

    struggletime-helper apikey <paste-key-here>

    Or open the tray → set API key…

  4. Start tracking a project 
    struggletime-helper start --repo ~/my-project

    Windows: use a full path, e.g. --repo C:\Users\you\my-project. Check: struggletime-helper status. Optional shell hooks add test/build signals; watching saved files and git in your project folder still works without them:

    # bash / zsh (Linux, macOS, WSL)
source /path/to/struggletime/daemon/hooks.sh

# PowerShell (Windows: add to $PROFILE)
. C:\path\to\struggletime\daemon\hooks.ps1

Privacy: only metadata leaves your machine (no code, prompts, or screenshots). Start with struggletime-helper start --repo ~/my-project.
