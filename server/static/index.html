how a minute earns its weight

1. steer — prompt or edit.  2. check — run the test or build, failing is fine.  3. follow through — edit again or commit. close that loop and the minute counts in full. leave an agent running unattended and it mostly doesn't.

integrations

github

link your github to a builder, and point your repo webhook at the url below. pushes show up as commit anchors, checked against your buckets.

webhook: post /v1/integrations/github/webhook (signed when github_webhook_secret is set)
repo info: get /v1/projects/{id}/github

slack

new submissions and reviews post to slack when slack_webhook_url is set (they queue under integration events until then). link your slack id to use the slash command.

slash command: /struggletime stats → post /v1/integrations/slack/command (signed when slack_signing_secret is set)
queued events: get /v1/integrations/events

struggletime is open source under agplv3. logged hours stay private, submitted hours are auditable. an hour submitted should mean an hour actually struggled toward something shipped.
