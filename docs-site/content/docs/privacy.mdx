## Guarantees

| Guarantee | Plain meaning |
|---|---|
| Native daemon | `struggletime-daemon` is a compiled binary — no scripting runtime on the machine |
| No screen / keystroke / prompt capture | No screenshots, OCR, keylogs, clipboard, or chat transcripts |
| No content / argv | File bodies and command arguments never leave the machine |
| Scrambled file IDs | On-wire identity is `sha256(salt:path)` hex, not absolute paths |
| Schema budget | Allowlisted JSON fields only; typical sealed slice ~25–50 KB |
| Tamper-evident history | Each local log entry carries `prev_hash` linking to the prior seal |

## What never leaves the machine

- Raw prompts, agent transcripts, chat logs
- Source file contents and unhashed absolute paths
- Command-line arguments and environment secrets
- Screenshots, window pixel buffers, microphone audio
- Keystroke streams or clipboard history

## Scrambled file IDs

```text
file_id = hex(sha256( f"{salt}:{absolute_or_repo_relative_path}" ))
```

Salt is local/config-scoped. The server sees opaque IDs, not path strings.

## Allowlisted schema

`POST /v1/buckets/batch` validates against a strict allowlist. Unknown fields
are rejected. Payloads stay small (~25–50 KB).

## Local history log (`.aitime-ledger.json`)

```text
entry_n.hash = H( canonical(entry_n without hash) )
entry_n.prev_hash = entry_{n-1}.hash
```

Quietly rewriting an old entry breaks the chain. Flush is ordered.
