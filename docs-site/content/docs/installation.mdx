## Requirements

- A release archive **or** a Rust toolchain to build from source
- Git
- Node 22+ only if you rebuild docs (`make docs`)

## Releases & prebuilt binaries

Download from [GitHub Releases](https://github.com/derekified/struggletime/releases)
(built on each `v*` tag). Each archive is **one** `struggletime` binary that
bundles:

- tray supervisor
- CLI (`status`, `start`, `apikey`, …)
- background tracker (`daemon`)
- local HTTP server (`serve`)

### macOS Universal (Apple Silicon + Intel)

```bash
curl -LO https://github.com/derekified/struggletime/releases/latest/download/struggletime-macos-universal.tar.gz
curl -LO https://github.com/derekified/struggletime/releases/latest/download/struggletime-macos-universal.tar.gz.sha256
shasum -a 256 -c struggletime-macos-universal.tar.gz.sha256
tar -xzf struggletime-macos-universal.tar.gz
chmod +x struggletime-macos-universal/struggletime
sudo install -m 755 struggletime-macos-universal/struggletime /usr/local/bin/struggletime
```

### Windows (x64)

```powershell
# Download struggletime-windows-x64.exe (+ .sha256) from Releases, then:
Get-FileHash .\struggletime-windows-x64.exe -Algorithm SHA256
# Compare to the hash in struggletime-windows-x64.exe.sha256 / SHA256SUMS.txt
# Put struggletime-windows-x64.exe on your PATH as struggletime.exe
```

A `.zip` of the same binary is also published. See
[Releases](https://github.com/derekified/struggletime/releases).

### Checksums

Every release includes `SHA256SUMS.txt`. Prefer verifying before first run.

## Build from source

```bash
git clone https://github.com/derekified/struggletime.git
cd struggletime
make rust
make install-binaries    # ~/.local/bin/struggletime
struggletime serve       # http://127.0.0.1:18765
```

## Sign in and API key

1. Continue with Hack Club Slack.
2. Claim a public handle if asked.
3. Settings → Profile → create a StruggleTime API key (`st_...`).
4. Paste it:

```bash
struggletime apikey <paste-key-here>
```

## Link a project

```bash
struggletime start --repo ~/my-project
struggletime status
struggletime tray          # optional supervisor
```

Shell hooks (exec categories only, never argv):

```bash
# bash / zsh
source /path/to/struggletime/daemon/hooks.sh

# PowerShell
. C:\path\to\struggletime\daemon\hooks.ps1
```

## Debug

```bash
STRUGGLETIME_DEBUG=1 struggletime daemon --repo ~/my-project
struggletime daemon --debug --repo ~/my-project
struggletime verify --ledger .aitime-ledger.json
make check                 # cargo test + adapter verify
```

Debug logs print allowlisted labels only (`editor`, `event_type`, counts).
Never paths, prompts, or argv.

## Config paths

| What | Where |
|---|---|
| Settings | `~/.config/struggletime/settings.json` (Windows: `%APPDATA%\struggletime\`) |
| Runtime logs | `~/.aitime/` |
| Local history log | `.aitime-ledger.json` in the watched repo |
