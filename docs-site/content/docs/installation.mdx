title: Installation
description: Install StruggleTime as a desktop app and CLI on macOS, Linux, and Windows.
---

Repo: [github.com/derekified/struggletime](https://github.com/derekified/struggletime).

StruggleTime ships as **one native binary** that is both:

- a **desktop tray app** (menu bar / notification area / AppIndicator)
- a **`struggletime` CLI** in your terminal

App mode and CLI mode share the same binary, the same SQLite/settings store, and
the same hash-chained ledger (`.aitime-ledger.json` with `prev_hash`). Paths leave
as salted IDs (`sha256(salt:path)`). Only allowlisted metadata (~25–50 KB per
bucket) is sealed — never prompts, transcripts, file contents, argv, or raw paths.

## Requirements

- A [GitHub Release](https://github.com/derekified/struggletime/releases) archive,
  **or** a Rust toolchain to build from source
- Git

## macOS (Universal — Apple Silicon + Intel)

```bash
curl -fLO https://github.com/derekified/struggletime/releases/latest/download/struggletime-macos-universal.tar.gz
curl -fLO https://github.com/derekified/struggletime/releases/latest/download/struggletime-macos-universal.tar.gz.sha256
shasum -a 256 -c struggletime-macos-universal.tar.gz.sha256
tar -xzf struggletime-macos-universal.tar.gz
sh struggletime-macos-universal/install.sh struggletime-macos-universal/struggletime
```

That installs:

- `StruggleTime.app` in `/Applications` (or `~/Applications`) — menu-bar app, no Dock icon (`LSUIElement`)
- `struggletime` on your PATH (`~/.local/bin` and `/usr/local/bin` when writable)

You can also open the ready-made `struggletime-macos-universal-app.zip` and drag
`StruggleTime.app` into Applications, then:

```bash
sudo ln -sf /Applications/StruggleTime.app/Contents/MacOS/struggletime /usr/local/bin/struggletime
```

### macOS Intel only

Same steps with `struggletime-macos-intel.tar.gz`.

### Check the install

```bash
struggletime --version
open -a StruggleTime          # tray
struggletime status           # CLI
```

Login autostart: `sh daemon/autostart.sh` (LaunchAgent calling `struggletime --tray`).

## Linux (x86_64)

Release Linux builds include the AppIndicator tray (`linux-tray` feature). Install
`libayatana-appindicator3` (or AppIndicator) for the icon. Without the library,
StruggleTime still runs a headless supervisor and keeps tracking.

```bash
curl -fLO https://github.com/derekified/struggletime/releases/latest/download/struggletime-linux-x86_64.tar.gz
curl -fLO https://github.com/derekified/struggletime/releases/latest/download/struggletime-linux-x86_64.tar.gz.sha256
sha256sum -c struggletime-linux-x86_64.tar.gz.sha256
tar -xzf struggletime-linux-x86_64.tar.gz
sh struggletime-linux-x86_64/install.sh struggletime-linux-x86_64/struggletime
```

That installs:

- `~/.local/bin/struggletime`
- `~/.local/share/applications/struggletime.desktop` (shows up as **StruggleTime**)
- `~/.config/autostart/struggletime.desktop` (login start; set `AUTOSTART_INSTALL=0` to skip)

```bash
struggletime --version
struggletime --tray           # or open StruggleTime from your app menu
struggletime status
```

## Windows (x64)

1. Download `struggletime-windows-x64.zip` from
   [Releases](https://github.com/derekified/struggletime/releases).
2. Extract, then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
# optional login start:
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Autostart
```

That installs:

- `%LocalAppData%\Programs\StruggleTime\struggletime.exe`
- **Start Menu → StruggleTime** (launches tray, no console window)
- user `PATH` so `struggletime` works in PowerShell, Command Prompt, and Windows Terminal

Open a **new** terminal:

```powershell
struggletime --version
struggletime apikey <st_…>
struggletime status
```

Double-clicking the app (or the Start Menu shortcut) starts the tray. Running
`struggletime status` from a terminal attaches to that console as a normal CLI.

## Sign in and API key

1. Continue with Hack Club Slack on the web dashboard.
2. Claim a public handle if asked.
3. Settings → Profile → create a StruggleTime API key (`st_...`).
4. Paste it into the tray (**set / link API key…**) or:

```bash
struggletime apikey <paste-key-here>
```

## Link a project

```bash
struggletime start --repo ~/my-project
struggletime status
struggletime --tray
```

Shell hooks (category labels only — never argv):

```bash
# bash / zsh
source /path/to/struggletime/daemon/hooks.sh

# PowerShell
. C:\path\to\struggletime\daemon\hooks.ps1
```

## Build from source

```bash
git clone https://github.com/derekified/struggletime.git
cd struggletime
make rust
make install                 # App + CLI via scripts/install.sh
struggletime serve           # http://127.0.0.1:18765
```

On Windows from source:

```powershell
cargo build --release -p struggletime --manifest-path rust\Cargo.toml
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

## Debug

```bash
STRUGGLETIME_DEBUG=1 struggletime daemon --repo ~/my-project
struggletime daemon --debug --repo ~/my-project
struggletime verify --ledger .aitime-ledger.json
make check
```

Debug logs print allowlisted labels only (`editor`, `event_type`, counts).
Never paths, prompts, or argv.

## Config paths

| What | Where |
|---|---|
| Settings | `~/.config/struggletime/settings.json` (Windows: `%APPDATA%\struggletime\`) |
| Runtime logs | `~/.aitime/` |
| Local history log | `.aitime-ledger.json` in the watched repo |
