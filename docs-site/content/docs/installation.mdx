## Requirements

- A release zip **or** a Rust toolchain to build from source
- Git
- Node 22+ only if you rebuild docs (`make docs`)

## Release zip (Windows / macOS / Linux)

Download from [GitHub Releases](https://github.com/derekified/struggletime/releases)
(built on each `v*` tag). Unpack and put these on your PATH:

- `struggletime-helper`
- `struggletime-daemon`
- `struggletime-server`
- `struggletime-tray`

## Build from source

```bash
git clone https://github.com/derekified/struggletime.git
cd struggletime
make rust
make install-binaries    # ~/.local/bin
struggletime-server      # http://127.0.0.1:18765
```

## Sign in and API key

1. Continue with Hack Club Slack.
2. Claim a public handle if asked.
3. Settings → Profile → create a StruggleTime API key (`st_...`).
4. Paste it:

```bash
struggletime-helper apikey <paste-key-here>
```

## Link a project

```bash
struggletime-helper start --repo ~/my-project
struggletime-helper status
struggletime-tray          # optional supervisor
```

Shell hooks (exec categories only, never argv):

```bash
# bash / zsh
source /path/to/struggletime/daemon/hooks.sh

# PowerShell
. C:\path\to\struggletime\daemon\hooks.ps1
```

## Debug

```bash
STRUGGLETIME_DEBUG=1 struggletime-daemon --repo ~/my-project
struggletime-daemon --debug --repo ~/my-project
make check                 # cargo test + adapter verify
```

Debug logs print allowlisted labels only (`editor`, `event_type`, counts) —
never paths, prompts, or argv.

## Config paths

| What | Where |
|---|---|
| Settings | `~/.config/struggletime/settings.json` (Windows: `%APPDATA%\struggletime\`) |
| Runtime logs | `~/.aitime/` |
| Local history log | `.aitime-ledger.json` in the watched repo |
