title: CLI and tray
description: StruggleTime single-binary CLI and tray supervisor.

The release binary is one executable: `struggletime`. Tray, CLI, daemon, and
local HTTP server all live inside it. Download from
[GitHub Releases](https://github.com/derekified/struggletime/releases).

## CLI

```bash
struggletime apikey <st_…>
struggletime start --repo ~/my-project
struggletime status
struggletime pause
struggletime resume
struggletime sync
struggletime stop
struggletime link --repo ~/my-project
struggletime logs
struggletime server          # show or set API URL
struggletime config          # settings path
struggletime verify --ledger .aitime-ledger.json
```

Settings live in `~/.config/struggletime/settings.json`. `start` re-launches
the same binary as `struggletime daemon` (or `STRUGGLETIME_DAEMON` if set).

## Daemon & server

```bash
struggletime daemon --repo ~/my-project
struggletime serve           # http://127.0.0.1:18765
```

## Tray

```bash
struggletime tray
```

Keeps the daemon running and prints a short status line. Put the release
binary on your PATH (`make install-binaries` or a
[Releases](https://github.com/derekified/struggletime/releases) archive).

Login autostart: `sh daemon/autostart.sh`.

## Privacy

Only allowlisted metadata is synced. Inspect what would be sealed by reading
`.aitime-ledger.json` in the project folder after a seal, or check
`struggletime logs`.
