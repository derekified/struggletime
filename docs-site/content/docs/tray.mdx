## struggletime-helper

```bash
struggletime-helper apikey <st_…>
struggletime-helper start --repo ~/my-project
struggletime-helper status
struggletime-helper pause
struggletime-helper resume
struggletime-helper sync
struggletime-helper stop
struggletime-helper link --repo ~/my-project
struggletime-helper logs
struggletime-helper server          # show URL
struggletime-helper config          # settings path
```

Settings live in `~/.config/struggletime/settings.json`. The helper starts
`struggletime-daemon` from the same install directory (or
`STRUGGLETIME_DAEMON`).

## Tray

```bash
struggletime-tray
```

Keeps the daemon running and prints a short status line. Use
`make install-binaries` or a release zip so `struggletime-helper` and
`struggletime-daemon` sit next to the tray binary.

Login autostart: `sh daemon/autostart.sh`.

## Privacy

Only allowlisted metadata is synced. Inspect what would be sealed by reading
`.aitime-ledger.json` in the project folder after a seal, or check
`struggletime-helper logs`.
