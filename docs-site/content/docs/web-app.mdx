## Surfaces

| Route / page | Who | Purpose |
|---|---|---|
| Landing `/` | Public | Docs link, sign-in |
| Home `/home` | Signed-in | Personal struggle summary |
| Stats | Signed-in | Breakdowns, projects, ranges |
| Builders | Signed-in | Leaderboard (opt-in) |
| Settings | Signed-in | Profile, customize, danger zone |
| Review / fraud | Staff roles | Submission queue and anomalies |
| `/docs/` | Public | Fumadocs site |

SPA navigation lives in `server/static/app.js`. Docs always open the Fumadocs export at `/docs/`.

## Dashboard customization

Settings -> Customize (and the home customize drawer):

| Control | What it changes |
|---|---|
| Metric mode | How primary hours/struggle metrics are framed |
| Calibration preset | Align display with labelled formula expectations |
| Layout / density | Compact vs roomy dashboard chrome |
| Colour scheme | Token-driven palette (shared with docs CSS variables) |

Preferences persist for the signed-in account. Docs and SPA share the same design tokens.

## Builders leaderboard

- Aggregates verified weighted hours across opted-in builders
- Structural totals only (no file trees or prompts)
- Opt-out controls live in Settings; leaving the board does not delete private history

## Roles and guards

| Role | Capabilities |
|---|---|
| User | Own projects, keys, stats, customize, opt-out |
| Reviewer / staff | Review queue, reason codes, deflations |
| Admin | Elevated fraud tools, dangerous account ops |

The SPA hides staff nav for non-staff. The API enforces the same guards.

## Danger zone

Settings -> Danger zone:

- Regenerate or revoke API keys (invalidates daemon auth immediately)
- Destructive account or data actions require explicit confirmation
- Soft-delete paths keep analytics filters from resurfacing PII

Stop the daemon or run `struggletime-helper apikey` after rotating keys.
