---
title: Getting started
description: Clone, build native binaries, run server and daemon.
---

```bash
git clone https://github.com/derekified/struggletime.git
cd struggletime
make check
make rust
make install-binaries
struggletime serve          # :18765
```

In another terminal:

```bash
struggletime apikey <st_…>    # from Settings
struggletime start --repo ~/my-project
struggletime status
```

Docs: `make docs`, then open `/docs/` on the running server.

See [Installation](/docs/installation) for release zips and Windows notes.
