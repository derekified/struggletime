---
title: Deployment
description: Run struggletime serve on a small VPS.
---

One small VPS runs the stack. Clients pre-roll time into buckets, so write load stays modest.

```bash
make rust
./rust/target/release/struggletime serve --bind 0.0.0.0 --port 18765
```

Environment (see `.env.example`): `PORT`, `BIND`, `SERVER_DB`, OAuth/Slack secrets as needed.

Example systemd unit:

```ini
[Service]
WorkingDirectory=/opt/struggletime
ExecStart=/opt/struggletime/rust/target/release/struggletime serve --bind 0.0.0.0 --port 18765
Restart=on-failure
```

Put Caddy or nginx in front for TLS. Serve `docs-site/out` under `/docs/` or let the process serve static files next to the SPA.
