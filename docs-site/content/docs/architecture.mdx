## Stack

```text
+---------------------------------------------+
|  StruggleTime tray / CLI (`struggletime`) |
+--------------------+------------------------+
                     | starts / pauses / links
+--------------------v------------------------+
|  struggletime daemon  (native, ~1s loop)    |
|  - watch saves and build caches             |
|  - optional hooks and IDE adapters          |
|  - seal -> .aitime-ledger.json              |
+--------------------+------------------------+
                     | POST /v1/buckets/batch
+--------------------v------------------------+
|  struggletime serve  (native HTTP)         |
|  - auth, projects, stats                    |
|  - allowlist schema                         |
|  - static SPA + Fumadocs under /docs        |
+--------------------+------------------------+
                     | same scoring rules
+--------------------v------------------------+
|  rust/crates/st-core + weighting/rules-*.yaml |
+---------------------------------------------+
```

## L1: Passive file tracking

No OCR. Structural footprints only:

- Scrambled file IDs (`sha256(salt:path)`)
- Build/test cache directory presence/mtime classes
- Exec category events from shell hooks (name/category, not argv)

## L2: Scoring what “counts”

`st-core` turns a sealed time slice into weighted seconds. `FORMULA_VERSION`
is stamped on every accepted bucket.

## Provenance

- Local append-only log with `prev_hash`
- Offline queue flushes in order when connectivity returns
