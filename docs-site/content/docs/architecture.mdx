## Stack

```text
+---------------------------------------------+
|  StruggleTime Tray / struggletime-helper    |
+--------------------+------------------------+
                     | starts / pauses / links
+--------------------v------------------------+
|  daemon/daemon.py  (stdlib, ~1s loop)       |

|  - seal -> .aitime-ledger.json              |

                     | POST /v1/buckets/batch
+--------------------v------------------------+

+--------------------+------------------------+
                     | same formula
+--------------------v------------------------+

+---------------------------------------------+
```

## L1: Passive tomography

No OCR. No window titles as content. Structural footprints only:

- `.git` object and index pulses
- Salted file IDs (`sha256(salt:path)`)
- Build/test cache directory presence/mtime classes
- Exec category events from shell hooks (name/category, not argv)

## L2: Causality weighting

`src/verify.py` turns a sealed bucket into weighted seconds:

| Concept | Role |
|---|---|
| Struggle / closed loop | Full weight |
| Fail -> fix -> pass | Full weight |
| Unverified dump | Heavy deflation |
| Silent follow-up | 5-12 minute taper |
| Idle after span | Gradual decay |

`FORMULA_VERSION` is stamped on every accepted bucket so reviewers know which rule set applied.

## Provenance

- Local append-only ledger with `prev_hash`
- Server stores chain heads per user/project
- Offline queue flushes in order when connectivity returns
- Review UI can flag `CHAIN_BROKEN` / `GIT_MISMATCH`
