# Docs notes

The live documentation site is built from `docs-site/` (Fumadocs):

```bash
make docs
make server   # serves /docs/ from docs-site/out
```

Clone / install links: https://github.com/derekified/struggletime

The markdown files in this folder are short developer notes and pointers.
Prefer editing `docs-site/content/docs/*.mdx` for anything users read in `/docs`.
